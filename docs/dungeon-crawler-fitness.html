What I'm building

Dungeon Crawler Fitness

A fitness game I designed. It started as a board game and is now becoming an app. I'm building its email program from zero, in public. When there are real numbers, they'll be here.

The game

Players finish quest cards made of bodyweight exercises to earn XP and gold, fight floor bosses, keep streaks alive, and level up a character across five skills. The design is locked, and a working prototype is being playtested.

The email plan

  1. Waitlist. An honest sign-up page on Kit: no fake scarcity, no invented testimonials, no results claims.
  2. Welcome series. Introduce the game and learn what each subscriber wants.
  3. Build log. Regular updates so the list stays warm until launch.
  4. Launch. A paced sequence that turns the waitlist into first players.
  5. Report. List growth, opens, clicks, and conversions, posted here.

Where it stands

Game designed. Prototype in playtesting. Waitlist page in progress.
