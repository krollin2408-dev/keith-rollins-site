Work/Strategy & brand

Value Positioning Framework

Customers raised cost concerns online. Leadership asked the team to answer them with value. Several people write promotions, emails, releases and ads, and each handled it differently.

My role
Framework lead
Brand
APMEX
Year
2026
Status
In progress

The four pillars

  1. Deep value during events. Real savings, with the at-spot campaign as the model.
  2. Assortment breadth. A product for every budget.
  3. Free tools. Value-adds stated explicitly.
  4. Club benefits. Membership value shown plainly.

Channel map

Discount depth and range for promotions and ads. A standing value-add line for email. Assortment and tools framed as customer value in press releases. Every new line is checked against APMEX voice standards so value never turns into hype or defensiveness.

Results

  • One shared language for cost concerns.
  • A standing value line built into email.
  • Guardrails that keep value messaging on-voice.
